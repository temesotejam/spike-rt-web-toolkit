# 2026年度 前半・後半競技コース ルール整理

この文書は、共有された競技説明スライド（「競技（前半）ルール」「競技（後半）ルール」、いずれも Ver2026-11-6）の内容を、ライントレースプログラムの開発で参照しやすいように整理したものです。

前半競技と後半競技は、コースも計測方法も異なるため、別の競技モードとして扱います。さらに、共有された「コース全体図」には **LコースとRコースの両方** が描かれています。前半・後半の区分とL/Rの区分は別のものとして整理し、片側だけを対象にしません。スライドに書かれていない条件は推測で補っていません。

## 1. 競技時間・試技回数

競技概要スライドには、次のように記載されています。

- 各チームの競技時間は「4分×2回」。
- 1回の持ち時間（4分）内であれば、試技回数に制限はない。

この時間・試技回数の記載は競技概要として整理しています。前半・後半それぞれへの割り当てや、2回の試技の実施順については、提示されたスライドだけでは確定できません。

## 2. 前半競技：2つの円を組み合わせたコース

### L/Rの配置

「コース全体図」では、下側の円形コースが **L・Rの2配置** で示されています。どちらも大小2つの円を組み合わせたコースですが、大小の円の左右位置や走行ラインの向きが左右で異なります。前半競技の資料を参照するときは、Lだけ・Rだけに限定せず、両方の配置を確認します。

### 競技内容

- 2つの円を組み合わせたコースを走行する。
- スタートラインから走行を開始する。
- 図に示された赤い三角形のマーカーの順にコースをたどる。
- ゴールラインを通過するまでの時間を競う。

### コース図の読み方

- 小さい円と大きい円が接するように配置されたコース。
- 図にはスタートライン、ゴールライン、および走行順を示す赤い三角形のマーカーが描かれている。
- コース全体図にはL/Rの両配置があり、円の大小の位置関係と走行ラインが左右で異なる。
- ルール説明スライドの赤い三角形マーカーと、全体図に描かれた黄色の方向マーカーは、各図の表現に従って読み分ける。
- 実際の走行時は、当日のL/Rのコース配置とスタート位置を確認する。

### スライドから確定できない点

- 前半競技のスタート操作にフォースセンサーを使うかどうか。
- 走行失敗時の記録方法。
- 2回の試技でコースの向きがどのように割り当てられるか。

これらは提示された前半競技スライドには明記されていないため、後半競技のルールを流用しません。

## 3. 後半競技：グリッド区間・外周区間を含むコース

### L/Rの配置

「コース全体図」では、上側のグリッド区間も **L・Rの両配置** が示されています。グリッドの色分け・配置は左右で異なり、外周側のラインやスタート／ゴール表示も左右それぞれにあります。後半競技もL/Rの両方を対象として確認し、片側の図だけでコースを定義しません。

### スタートと走行順

- 指定されたスタートラインより後ろからスタートする。
- スタート操作はフォースセンサーの押下によって行う。
- コース図に示された ①〜⑨ の順に走行する。

### 紙コップと走行時間の記録

- コース図の橙色のサークル内、2か所に紙コップを置く。
- 赤色マーカー上に置かれた紙コップに、ロボットの先端が触れるまでを走行時間の記録とする。

紙コップへの接触を計測イベントとして扱います。接触判定に使うセンサーや、2か所それぞれの計測値の採点上の扱いは、スライドには明記されていません。

### ゴールできなかった場合の記録

- ゴールまで到達できなかった場合は、到達した最も遠い赤線の位置を記録とする。
- この到達位置による記録の対象として、スライドには ②〜⑥、⑧ が注記されている。

### ライントレース後のボーナスポイント

ライントレース後に、次のボーナスポイントが示されています。

1. 指定されたエリアに停止する。
2. 音楽を鳴らす。

スライド上ではこの2項目がボーナスポイントとして記載されています。両方の達成が必須か、どちらかを選択するのか、配点がどうなるかは提示資料だけでは判断できません。

## 4. 後半競技スライドに記載されたセンサー構成

後半競技のコース図には、次の構成が記載されています。

| センサー | 数・構成 |
| --- | --- |
| 距離センサー | 2個 |
| カラーセンサー | 2個 |
| フォースセンサー | 2個 |
| ジャイロセンサー | 6軸ジャイロセンサー（ハブに内蔵） |

この表はスライドに記載された機材情報の転記です。各センサーをどのイベントの判定に使用するかまでは指定されていません。

## 5. 前半・後半の違い

| 項目 | 前半競技 | 後半競技 |
| --- | --- | --- |
| コース | L/Rそれぞれに大小2つの円を組み合わせたコース | L/Rそれぞれにグリッド区間と外周区間を含むコース |
| 走行順 | 図中の赤い三角形マーカーの順 | ①〜⑨ |
| スタート | スタートラインから | 指定ラインより後ろ。フォースセンサー押下で開始 |
| 主な記録 | ゴールライン通過までの時間 | 紙コップへの接触までの時間。未到達時は最遠到達赤線位置 |
| 追加課題 | スライドに記載なし | 停止・音楽再生のボーナスポイント |

## 6. プログラム開発での扱い（ルールからの整理）

以下は競技ルールそのものではなく、プログラムを設計する際の整理です。

- 前半・後半を別モードとして分ける。共通化できるライントレース制御は共有してよいが、コース進行・計測・終了判定は分離する。
- L/Rの両配置を扱えるようにする。左右でコースの向きやマーカー配置が異なるため、片側の座標・走行順をそのまま反対側へ流用できるとは限らない。
- 前半は、赤い三角形の順に沿って走行し、ゴールライン通過を計測終了イベントとする。
- 後半は、フォースセンサー押下をスタートイベントとし、①〜⑨の順序管理、紙コップ接触の記録、未到達時の最遠到達位置の記録、ボーナス課題を個別に管理する。
- センサー構成の記載だけから検出方法を決めつけない。紙コップ接触やマーカー検出にどのセンサーを使うかは、実機の配置・仕様を確認して決める。
- 競技時間の残り時間と、各試技の走行時間・到達位置は別々に記録できる構成にする。

## 7. 追加確認が必要な事項

提示されたスライドだけでは、次の事項は確定できません。

- 前半競技のスタート操作方法。
- 前半競技でゴールできなかった場合の記録方法。
- 4分×2回が前半・後半にどう割り当てられるか。
- 後半の紙コップ2か所の計測値の扱いと採点方法。
- ボーナスポイントの停止・音楽再生が両方必須か、選択式か、および配点。
- 赤線・赤色マーカーの検出方法と、各センサーの具体的な担当。
- L/Rそれぞれの走行開始位置、走行方向、試技での使用順・割り当て。

ルールが追加で分かった場合は、この文書の「追加確認が必要な事項」を更新し、確定事項と未確定事項を分けて管理します。
