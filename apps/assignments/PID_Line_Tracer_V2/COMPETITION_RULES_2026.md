# 2026年度 前半・後半競技ルールとコース経路の整理

この文書は、共有された競技説明スライド（「競技（前半）ルール」「競技（後半）ルール」、Ver2026-11-6）と、前半競技コース図・コース全体図に基づく整理です。

**前半競技と後半競技は、同じライントレースコース形状を利用します。前半競技は後半競技のライントレースコースの一部分を使いますが、走行する経路の選び方・回り方・通過順が異なります。** コースの物理的な形状やライン配置が前半用・後半用に変化するわけではありません。L/Rは同じコースに用意された左右の配置を示し、前半・後半の区分とは別です。

## 1. 競技時間・試技回数

競技概要スライドには、次のように記載されています。

- 各チームの競技は「4分×2回」。
- 1回の持ち時間（4分）内であれば、試技回数に制限はない。

提示資料だけでは、4分×2回が前半・後半にどのように割り当てられるか、またL/Rの使用順がどうなるかまでは確定できません。

## 2. 前半競技：共通コースの一部分を使う走行ルート

### コース経路

前半競技は、**後半競技でも使用する同じライントレースコースの一部分**を利用します。前半ではその一部分を、前半ルール図に示された順序・回り方で走行します。後半とコース形状が異なるのではなく、同じライン上で走行対象となる区間や通過順・回り方が異なります。

- スタートラインから走行を開始する。
- 図に示された赤い三角形のマーカーの順に移動する。
- ゴールラインを通過するまでの時間を競う。

### L/Rの違い

前半競技コース図にはL/Rの2配置があります。L/Rは同じコース形状に対する左右の配置です。前半競技では、そのそれぞれで前半ルール図に示された走行ルートをたどります。

### 前半競技で確認できること

- 前半ルール図で指定された、共通コースの一部分を使う走行ルート。
- その部分には大小2つの円形ループが含まれる。
- スタート位置とゴール位置が指定されている。
- 赤い三角形のマーカーの順に走行する。
- 評価対象はゴールライン通過までの時間。

### 前半競技資料で明記されていないこと

- スタート操作にフォースセンサーを使うかどうか。
- ゴールできなかった場合の記録方法。
- 4分×2回の時間配分とL/Rの試技割り当て。

後半競技のフォースセンサースタートや未到達時の記録ルールを、前半競技に流用しません。

## 3. 後半競技：共通コース全体を使うライントレース

後半競技は、**共通のライントレースコースを後半コース図に示された順序・回り方で走行する競技**です。前半競技とは同じコース形状を利用しますが、走行対象区間・通過順・回り方が異なります。

後半コース図は、上側のグリッド状のラインだけではありません。コース全体図では、グリッド区間から下側の円形・曲線区間、外周のラインまでが一続きの同じライントレースコースとして描かれています。後半競技では、このコース全体を後半ルール図に示された①〜⑨の順序・回り方で走行します。前半競技もこの同じコースの一部分を利用しますが、前半ルール図に示された別の走行ルートをたどります。後半ルールの詳細図には、後半の走行順、スタート位置、紙コップ位置、ボーナスポイント位置が示されています。コース全体図はL/R両方を示し、後半ルールの詳細図はR側の説明図です。

### スタートと走行順

- 図に示されたスタートラインより後ろからスタートする。
- **フォースセンサーを押下してスタートする。**
- 後半競技ルール図に示された **①〜⑨の順** に走行する。

### 紙コップと走行時間の記録

- 橙色のサークル内の2か所に紙コップを置く。
- 赤色マーカー上に置かれた紙コップに、ロボットの先端が触れるまでを走行時間の記録とする。

紙コップへの接触が記録イベントです。2か所の計測値の採点上の扱いや、接触検出にどのセンサーを使うかは、提示スライドだけでは確定できません。

### ゴールできなかった場合の記録

- ゴールまで到達できなかった場合は、到達した最も遠い赤線の位置を記録とする。
- 対象位置として、スライドには **②〜⑥、⑧** が注記されている。

### ライントレース後のボーナスポイント

ライントレース後のボーナスポイントとして、次の2項目が示されています。

1. 指定されたエリアに停止する。
2. 音楽を鳴らす。

提示スライドだけでは、両方の達成が必須か、選択式か、配点がどうなるかは確定できません。

### 後半競技スライドに記載されたセンサー構成

| センサー | 数・構成 |
| --- | --- |
| 距離センサー | 2個 |
| カラーセンサー | 2個 |
| フォースセンサー | 2個 |
| ジャイロセンサー | 6軸ジャイロセンサー（ハブに内蔵） |

これはスライドに記載された構成の転記です。各センサーの具体的な担当までは指定されていません。

### L/Rの違い

コース全体図にはL/R両方の後半コースが示されています。グリッドの色・配置、円形区間の大小の位置、外周ラインなどが左右で異なります。後半競技ルールの詳細図はR側を示していますが、全体図にあるL側も別レイアウトとして扱います。

## 4. 前半競技と後半競技の違い

**コース形状は共通で、違うのは走行ルートです。** 前半競技は後半競技のライントレースコースの一部分を使い、前半用の順序・回り方で走行します。後半競技は後半コース図に示された経路を走行します。

| 項目 | 前半競技 | 後半競技 |
| --- | --- | --- |
| 経路 | 共通コースの一部分を使い、前半ルール図の順序・回り方で走行 | 同じ共通コースを、後半ルール図の①〜⑨の順序・回り方で走行 |
| 走行順 | 前半ルール図の赤い三角形マーカーの順 | 後半ルール図の①〜⑨ |
| スタート | スタートラインから | 指定ラインより後ろ。フォースセンサー押下で開始 |
| 主な記録 | ゴールライン通過までの時間 | 紙コップ接触までの時間。未到達時は指定された最遠到達赤線位置 |
| 追加課題 | 提示スライドに記載なし | ライントレース後の停止・音楽再生ボーナスポイント |
| L/R | L/Rで円の大小位置・経路向きが異なる | L/Rでグリッド配置・円形区間・外周ラインが異なる |

## 5. プログラム開発での扱い

以下は競技ルールそのものではなく、プログラム設計上の整理です。

- **コース形状・ライン配置は共通のコースマップとして一度だけ定義する。** 前半用・後半用に別々のコース形状を作らない。
- 前半・後半は走行ルート設定を分ける。前半は共通コースの一部分を前半ルール図の順序・回り方で走行し、後半は共通コースを後半ルール図の①〜⑨の順序・回り方で走行する。
- PIDなどの低レベルなライン追従処理は共通化し、走行ルート、マーカー順、スタート条件、ゴール判定、計測処理は競技ごとに管理する。
- L/Rは同じコース形状に対する左右の配置として扱い、それぞれに対応する走行ルート設定を用意する。単純な左右反転だけで同じ走行順・同じ座標が使えるとは決めつけない。
- センサー構成だけから検出方法を決めつけない。実機でのセンサー配置・役割を確認してから実装する。

## 6. 追加確認が必要な事項

提示されたスライドだけでは、次の事項は確定できません。

- 前半競技のスタート操作方法と、ゴールできなかった場合の記録方法。
- 4分×2回が前半・後半にどう割り当てられるか。
- L/Rの試技順・割り当て。
- 後半の紙コップ2か所の計測値の扱いと採点方法。
- ボーナスポイントの停止・音楽再生が両方必須か、選択式か、および配点。
- 赤線・赤色マーカー・紙コップの検出方法と、各センサーの具体的な担当。

ルールが追加で分かった場合は、確定事項と未確定事項を分けて更新します。
