Windows 初回設定

WindowsでこのページのWebUSB書き込みを初めて使うPCでは、DFUモードのHubへWinUSBを設定する必要がある場合があります。専用ツールはLEGO SPIKE Prime / Technic Large HubのDFUモード 0694:0008 だけを対象にします。

WinUSBセットアップをダウンロード Releasesを開く
初回設定の手順
  1. 上のボタンからWindows用の単一EXEをダウンロードします。
  2. HubをDFUモードにしてUSB接続します。
  3. SPIKE-RT-DFU-WinUSB-Setup-v0.3.exeを起動します。
  4. 「準備完了」と表示されたらツールを閉じ、このページへ戻ります。

WinUSBセットアップはDFU用USB 0694:0008 だけを対象とし、SPIKE-RT実行中のUSBシリアル / COMポートは変更しません。すでにWinUSB設定済みの場合は何も変更せず「準備完了」と表示します。

配布版: v0.3.0 pre-release / Windows x64 / 単一EXE。新規WinUSB割り当て経路は未設定PCでの最終実機確認待ちです。

2. SPIKE Hubへ接続

DFUモードでの接続手順
  1. Hubの電源を切り、USBケーブルを抜きます。
  2. Bluetoothボタンを押したままUSBケーブルを接続します。
  3. ボタンが赤・緑・青に繰り返し点滅したらボタンを離します。
  4. 「Hubに接続」を押し、LEGO Technic Large Hub in DFU Modeを選択します。

Windows: WebUSBでHubを選択できない場合は、上の「Windows 初回設定」から専用WinUSBセットアップを実行してください。

3. 書き込み

アプリ領域0x08008000以外への書き込みと、992 KiBを超えるファイルはコード上で拒否します。処理はセクタ消去、分割書き込み、DFU状態確認、SPIKE-RT v0.2.0公式と同じブート先0x08000000を指定したDFU終了・再起動の順に行います。
